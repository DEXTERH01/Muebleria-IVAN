# Fuentes de imágenes del catálogo

`unsplash_image_sources.csv` conserva las fuentes, autores y licencia de las imágenes
referenciales del catálogo. El cargador `scripts/upload_catalog_image_bank.py` descarga
cada URL y la sube a Cloudinary sin guardar las credenciales ni copias locales.

Las imágenes representan modelos referenciales personalizables. No se deben describir
como trabajos ya fabricados por Mueblería Iván.
